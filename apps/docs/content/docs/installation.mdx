## Install a release

Download an archive for your platform from [GitHub Releases](https://github.com/gillesmag/folio/releases). Repository access is required for private releases.

| Platform             | Archive                                  |
| -------------------- | ---------------------------------------- |
| macOS, Apple Silicon | `folio-aarch64-apple-darwin.tar.xz`      |
| macOS, Intel         | `folio-x86_64-apple-darwin.tar.xz`       |
| Linux, ARM64         | `folio-aarch64-unknown-linux-gnu.tar.xz` |
| Linux, x64           | `folio-x86_64-unknown-linux-gnu.tar.xz`  |
| Windows, x64         | `folio-x86_64-pc-windows-msvc.zip`       |

Extract the archive. Put the `folio` binary, or `folio.exe` on Windows, in a directory on your `PATH`.

For Linux x64, this example downloads a specific release with the GitHub CLI. Replace `v0.1.0` with your release tag:

```sh
gh release download v0.1.0 --repo gillesmag/folio \
	--pattern 'folio-x86_64-unknown-linux-gnu.tar.xz*'
sha256sum --check folio-x86_64-unknown-linux-gnu.tar.xz.sha256
tar -xJf folio-x86_64-unknown-linux-gnu.tar.xz
mkdir -p "$HOME/.local/bin"
install -m 755 folio-x86_64-unknown-linux-gnu/folio "$HOME/.local/bin/folio"
```

On macOS, check the archive with `shasum -a 256 --check` and its matching checksum file.

## Build from source

Install a current stable Rust toolchain. From a checkout of the repository, run:

```sh
cargo install --locked --path cli
```

Cargo installs the executable in its binary directory, usually `~/.cargo/bin`.

## Verify the installation

```sh
folio --version
folio --help
```
