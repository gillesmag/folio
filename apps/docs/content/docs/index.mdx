Folio turns Markdown into a document you can read in a browser. Documents support code highlighting, tables, math, and Mermaid diagrams. Comments can refer to a specific block or the whole document.

You can create and edit documents in the web app, push local files with the CLI, or call the HTTP API from a script. Each account has its own document list. New documents are private.

## Documentation for agents

[llms.txt](/llms.txt) indexes the documentation. [llms-full.txt](/llms-full.txt) contains every page as Markdown, including endpoint schemas. Each page also has a **View as Markdown** link.

The documentation website is separate from your Folio instance. API requests and CLI commands use the web app's origin.
